# 135 排版规则

仅在用户要求 135 编辑器、微信公众号排版或完整排版源码时读取本文件。

## 母版

- 使用 `assets/135-wechat-template.html`。
- 母版来自用户在 135 编辑器中调整并同步成功的版本。
- 保留头图城市图、白色文字卡片、各栏目横向连体标题条、新闻卡片和尾图的结构与内联样式。
- 所有新闻卡片左右边缘必须与栏目标题整体左右边缘对齐。

## 图片

- 城市图与尾图必须使用母版内 `mmbiz.qpic.cn` / `sz_mmbiz_jpg` 的微信素材地址。
- 禁止换回本地路径、`chatgpt.site` 外链或带 `auth_key` 的 `bexp.135editor.com` 临时地址。
- 不要把城市图和白色文字卡片合并成新图片；白卡片文字需保持可编辑。
- 输出前搜索 `auth_key`、`bexp.135editor.com` 和 `file:`，任一存在都不得交付。

## 可变内容

- 更新头图日期与星期。
- 更新栏目编号、中文名、英文名以及每条新闻标题和正文。
- 新闻标题使用母版字号，不擅自放大；日期保持常规字重。
- 英文问候语和末行中文属于同一信息组，保留母版中的紧凑间距。
- 结尾文案固定为“产业朝闻  企业发展智慧之选”，尾图紧随其后，沿用母版间距。

## 标题排版硬规则

- 标题、正文和来源标签使用同一左右内容边界。
- 标题从左边界开始自然换行；完整的非末行两端对齐到正文右边界，末行和短标题自然靠左。
- 不得把整段标题右对齐，不得把末行右对齐，不得用空格、手动换行、text-wrap: balance 或夸张字距伪造对齐。
- 标题字号16px、行高1.45、字距0；标题内的 span、strong 等嵌套标签也必须字距0，不能覆盖标题规则。
- 正文维持母版15px、行高1.8和原有字距，不因调整标题而改变。
- 规则由 scripts/normalize_layout.py 统一处理，并由 scripts/render_135.py 在生成后再次套用，避免只改预览、不改正式稿。

## 手机检查

- 必须检查375、390、430像素宽度。
- 至少检查长标题、短标题、含数字和括号的标题。
- 标题与正文不能重叠、溢出或出现不一致的左右边界；两张固定图片必须加载且宽度不超出内容区。

## 交付检查

- 交付HTML文件、完整HTML源码TXT和来源核查表三个文件链接；HTML与TXT内容完全一致，不含Markdown围栏。回复另展示完整html代码块，除非用户只要文件。
- 预览时确认城市图和尾图均可加载，头图白卡片保留投影且无灰色底块。
- 不依赖脚本、外部样式表或公众号会过滤的交互代码。
